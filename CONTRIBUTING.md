# Contributing to FinCore

Thank you for your interest in contributing to FinCore.

FinCore is an open-source project built to improve how financial products are designed, developed, and implemented with AI.

We welcome contributions from:

* Designers
* Developers
* Product Thinkers
* Technical Writers
* Accessibility Advocates

---

## Ways to Contribute

### Design

* Design Foundations
* Components
* Patterns
* Accessibility Reviews

### Development

* Components
* Documentation
* Tooling
* Testing

### Documentation

* Guides
* Examples
* Tutorials
* AI Context Files

---

## Before Contributing

Please:

1. Check existing issues.
2. Discuss major changes before implementation.
3. Follow FinCore design principles.
4. Prioritize accessibility.

---

## Design Principles

All contributions should align with:

* Trust First
* Clarity Over Decoration
* Mobile First
* Accessibility by Default
* AI Ready
