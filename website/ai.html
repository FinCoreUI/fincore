Use with a tool

Give the tool the smallest set of files it needs. For most code tasks, start with ai/agent.md, then add ai/components.md and the matching contract.

Read ai/agent.md and ai/components.md.
Use only Button, Input, PasswordInput and PhoneInput.
Do not invent props, tokens or components.
Load tokens.css before component CSS.

Non-negotiable rules

  • Only four components exist.
  • Contracts are authoritative.
  • No invented props, variants, tokens or Figma node IDs.
  • Native controls, labels and semantic errors.
  • No dark mode simulation.
  • No phone deliverability claims.
  • No claim that the private packages are public.
  • No claim of screen-reader or cross-browser certification.

What the AI layer is not

It is not a hosted AI service, a retrieval index or a chatbot. It is a set of versioned Markdown files in the repository. There is no telemetry and no external API call.
