Components

Twelve canonical components. Full contract validation, dark theme, and size/loading variant support. Each one has a contract, canonical CSS, native reference markup and a React adapter.

Button

A native <button>. Defaults to type="button" and the primary variant. Open Interactive Button Playground →

import { Button } from "@sorleed/react";

<Button variant="primary">Continue</Button>
<Button variant="secondary">Cancel</Button>
<Button variant="ghost">Back</Button>
<Button disabled>Unavailable</Button>
PropTypeDefaultNotes
variant"primary" | "secondary" | "ghost""primary"Visual variant.
typeNative button type"button"Prevents accidental form submission.
native attributesButtonHTMLAttributes—disabled, aria-*, data-* pass through.

States: default, hover, active, focus-visible and disabled. Disabled wins over every other state.

Input

A native text-like input with a required label, optional helper and explicit error state. Open Interactive Input Playground →

We only use this for account notices.

Account number must be 10 digits.

import { Input } from "@sorleed/react";

<Input label="Email" type="email" placeholder="you@example.com" />
<Input label="Name" helperText="Enter your full name." />
<Input
  label="Account number"
  value={value}
  onChange={(event) => setValue(event.target.value)}
  errorMessage={error}
/>
PropTypeNotes
labelstringRequired. Visible or visually hidden.
hideLabelbooleanHides visually; keeps the accessible name.
helperTextstringShown when there is no error.
errorMessagestringReplaces helper text and sets aria-invalid.
type"text" | "email" | "tel" | "number" | "url"Other types are out of scope.
idstringGenerated when omitted.

PasswordInput

A password input with a real toggle button. The toggle reports its state with aria-pressed.

Use at least 12 characters.

import { PasswordInput } from "@sorleed/react";

<PasswordInput
  label="Password"
  autoComplete="current-password"
  helperText="Use at least 12 characters."
/>
PropTypeDefaultNotes
labelstring—Required.
hideLabelbooleanfalseVisually hides the label.
helperTextstring—Shown when there is no error.
errorMessagestring—Sets aria-invalid.
visibleboolean—Controlled visibility.
defaultVisiblebooleanfalseUncontrolled initial visibility.
onVisibleChange(visible: boolean) => void—Toggle callback.
showPasswordLabelstring"Show password"Accessible toggle name.
hidePasswordLabelstring"Hide password"Accessible toggle name.

PhoneInput

A phone field with a native country selector and optional libphonenumber-js validation. No IP geolocation and no forced default country.

Dial code: +. Include your country code.

import { PhoneInput } from "@sorleed/react/phone-input";

<PhoneInput
  label="Phone number"
  helperText="Include your country code."
  onChange={({ inputValue, e164, country, status, isValid }) => {
    // The application decides what to display.
  }}
/>
PropTypeNotes
labelstringRequired.
value / defaultValuestringControlled or uncontrolled editing value.
country / defaultCountrystringISO 3166-1 alpha-2. Never inferred from IP.
countriesstring[]Optional ISO allow-list.
onChange(result: PhoneInputChangeResult) => voidReports editing value and status.
onCountryChange(country?: string) => voidSelector callback.
errorMessagestringSets aria-invalid and shows the message.
internationalbooleanAccepted for compatibility; does not change behaviour yet.

isValid means numbering-plan format validity. It does not prove that a number is active, reachable or owned.

Select

A native <select> dropdown with associated label, control wrapper, and message row. Supports sm, md, and lg sizes plus loading states.

Checkbox

Accessible native checkbox input with persistent label and error/helper text wiring.

Radio Group

Group of native radio inputs sharing a common name for mutual exclusion and accessible keyboard navigation.

Textarea

Multi-line native <textarea> control with flexible resize behavior, size variants, and loading support.

OTP

Group of single-character inputs supporting automatic advance, backspace navigation, and paste handling.

Currency

Financial input control with configurable prefix (e.g. $) and suffix currency symbols.

CVV

Short fixed-length masked input for payment card verification with optional visibility toggle.

DatePicker

Native date field with accessible label associations, min/max range limits, and validation states.

Shared rules

  • Native elements only. No custom listbox or hidden input tricks.
  • Every field has a programmatic label.
  • Focus is an additive overlay, visible for keyboard and pointer focus.
  • Disabled wins over hover, error and focus.
  • Errors are never colour-only; a message is required.
  • No state, variant or prop outside the contract.
