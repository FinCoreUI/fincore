Button

Canonical CSS + React

A native <button> element with strict visual hierarchy, accessible keyboard focus rings, and dark theme support. Defaults to type="button".

Interactive Playground

import { Button } from "@sorleed/react";

<Button variant="primary" size="md">
  Continue
</Button>
<button class="fc-button fc-button--primary" type="button">
  Continue
</button>

Props & Controls

Component Props

PropTypeDefaultDescription
variant"primary" | "secondary" | "ghost""primary"Visual styling hierarchy.
size"sm" | "md" | "lg""md"Geometric height and padding.
loadingbooleanfalseDisplays loading indicator and sets aria-busy="true".
disabledbooleanfalseNative disabled state; suppresses hover and focus.
type"button" | "submit" | "reset""button"Native button type to prevent accidental submission.

Design Tokens

Button styles are powered entirely by --fc-button-* design tokens:

  • --fc-button-primary-background / --fc-button-primary-foreground
  • --fc-button-secondary-background / --fc-button-secondary-foreground
  • --fc-button-ghost-foreground
  • --fc-button-focus-color / --fc-button-focus-width / --fc-button-focus-offset
  • --fc-button-radius / --fc-button-height / --fc-button-padding-x
