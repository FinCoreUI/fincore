Input

Canonical CSS + React

A native text-like input with required accessible label association, optional helper text, explicit error state handling, and dark theme support.

Interactive Playground

We will send receipts to this email address. 

import { Input } from "@sorleed/react";

<Input
  label="Account email"
  placeholder="name@example.com"
  helperText="We will send receipts to this email address."
/>
<div class="fc-input">
  <label class="fc-input__label" for="demo-input">Account email</label>
  <div class="fc-input__control">
    <input class="fc-input__field" id="demo-input" placeholder="name@example.com" aria-describedby="demo-input-message">
  </div>
  <p class="fc-input__message" id="demo-input-message">We will send receipts to this email address.</p>
</div>

Props & Controls

Component Props

PropTypeDefaultDescription
labelstringRequiredAccessible name for the field. Associated via htmlFor/id.
hideLabelbooleanfalseKeeps label in accessibility tree but visually hidden.
helperTextstring—Optional explanatory helper copy.
errorMessagestring—Triggers error state and applies aria-invalid="true".
size"sm" | "md" | "lg""md"Geometric control height.
loadingbooleanfalseDisplays loading indicator and sets aria-busy="true".
disabledbooleanfalseNative disabled state; suppresses hover, error, and focus rings.

Design Tokens

Input components consume semantic --fc-input-* tokens:

  • --fc-input-background / --fc-input-text / --fc-input-placeholder
  • --fc-input-border / --fc-input-border-hover / --fc-input-border-error / --fc-input-border-disabled
  • --fc-input-focus-color / --fc-input-focus-width / --fc-input-focus-offset
  • --fc-input-label-color / --fc-input-label-font-weight / --fc-input-label-gap
  • --fc-input-helper-color / --fc-input-helper-gap / --fc-input-text-error
