Customisation

Sorleed is designed to be owned. Customise at the token layer or by editing copied source. Keep the contracts intact.

Principles

  1. Override semantic roles, not component internals. Component CSS should keep consuming --sl-button-*, --sl-input-* and --sl-phone-input-*.
  2. Keep the alias chain. A component token aliases a semantic role; a semantic role aliases a primitive.
  3. Revalidate contrast. Every colour change affects text, boundary, focus or error contrast.
  4. Edit your copy. With the CLI, the source is yours. Re-running the CLI will not overwrite it.

Token overrides

/* app-theme.css — load after tokens.css */
:root {
  --sl-color-content-primary: #111827;
  --sl-color-border-focus: #0f766e;
  --sl-color-surface-muted: #f3f4f6;
}

For a compiled package, import the Sorleed stylesheets first and the theme layer second:

import "@sorleed/react/styles/tokens.css";
import "@sorleed/react/styles/button.css";
import "./app-theme.css";

Source edits

With the CLI, the copied files are ordinary source:

components/sorleed/button/index.tsx
styles/sorleed/button.css
styles/sorleed/tokens.css

You can change layout, copy and composition. If you add a new visual state, record it in a new contract and test it. Do not add an undocumented state to an existing component.

Brand palette

Sorleed does not force a brand palette. The shipped palette is a reference implementation. To use your own:

  1. Map your brand colours to the semantic roles you need.
  2. Keep component tokens as aliases to those roles.
  3. Run node tokens/check.mjs if you maintain a local token source.
  4. Check focus, boundary, text and error contrast in the browser.

What not to do

  • Do not consume primitive or semantic tokens from component CSS.
  • Do not add success, warning, info or loading states that the contract does not define.
  • Do not simulate dark mode by inverting values.
  • Do not force a default country or use IP geolocation.
  • Do not claim a phone number is reachable, active or owned.
  • Do not replace native controls with inaccessible custom widgets.
