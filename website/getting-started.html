Getting started

Three supported ways to consume Sorleed. Choose the one that matches how much source you want to own.

React package

The package is private alpha and unpublished. When it is available to your environment:

npm install @sorleed/react react react-dom
# optional, only for PhoneInput
npm install libphonenumber-js

Import components and the generated CSS:

import { Button, Input, PasswordInput } from "@sorleed/react";
import { PhoneInput } from "@sorleed/react/phone-input";
import "@sorleed/react/styles/tokens.css";
import "@sorleed/react/styles/button.css";
import "@sorleed/react/styles/input.css";
import "@sorleed/react/styles/password-input.css";
import "@sorleed/react/styles/phone-input.css";

All five stylesheets are exported by the package. The package is ESM and ships TypeScript declarations.

CLI source distribution

The CLI copies canonical source into your project so you can edit it:

npx sorleed list
npx sorleed add button --dir ./my-app
npx sorleed add input --dir ./my-app
npx sorleed add password-input --dir ./my-app
npx sorleed add phone-input --dir ./my-app

Each install copies:

components/sorleed/<component>/index.tsx
components/sorleed/types/index.ts      (shared)
styles/sorleed/<component>.css
styles/sorleed/tokens.css              (shared)

Existing files are never overwritten. Use --dry-run to preview an install.

Plain HTML and CSS

No build step and no package manager are required for the core implementation:

<link rel="stylesheet" href="tokens/dist/tokens.css">
<link rel="stylesheet" href="components/button/button.css">

<button class="sl-button sl-button--primary" type="button">Continue</button>

Use the canonical markup from components/<component>/<component>.html as the starting point.

CSS order

  1. tokens.css
  2. component stylesheets

Component stylesheets do not import tokens automatically. Loading a component sheet without the token sheet leaves its variables undefined.

Requirements

SurfaceRequirement
Core HTML/CSSAny modern browser. No runtime or build step.
@sorleed/reactReact 18+ and React DOM 18+. ESM tooling; Node 18+ for build tooling.
@sorleed/cliNode 18+ with ESM support. CSS imports need a bundler.
PhoneInputlibphonenumber-js for parsing and format validation.

Verify the install

Render a Button and an Input. Confirm that the button has a visible focus ring and that the input label is associated. If the styles are missing, check that tokens.css loads first.

Helper text is connected to the field.

Unpublished packages. Do not add @sorleed/react or @sorleed/cli to a public dependency list until they are published. The repository and CI validate packed artifacts, but publication is a separate, owner-authorised step.
