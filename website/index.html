UI infrastructure you can own.

Sorleed is a source-first UI toolkit for designers and developers. Four carefully specified components, one token system, a source-distribution CLI and AI context that describes what actually exists.

What is in the box

Sorleed UI

Button, Input, PasswordInput and PhoneInput. Native elements, visible focus, explicit states and no hidden behaviour.

Sorleed Tokens

229 --sl-* custom properties across primitive, semantic and component layers. Generated CSS, reproducible output.

Sorleed CLI

Copy canonical component source into your project. Existing files are never silently overwritten.

Sorleed AI

Context files for AI coding tools, with explicit rules against inventing components, props or tokens.

Sorleed Figma

Token import, component specifications and SVG evidence prepared for a Figma library. No Community Library is published yet.

Sorleed Website

This static documentation site. No tracking, no build step and no external runtime.

Install

Use the React package when it is available in your environment, or copy source with the CLI.

npm install @sorleed/react react react-dom

import { Button } from "@sorleed/react";
import "@sorleed/react/styles/tokens.css";
import "@sorleed/react/styles/button.css";

Or copy the canonical source:

npx sorleed list
npx sorleed add button --dir ./my-app

Alpha status. @sorleed/react and @sorleed/cli are private and unpublished. This site documents the implementation that exists in the repository; it is not a public release announcement.
