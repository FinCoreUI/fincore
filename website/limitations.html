Limitations and support

What is not here, stated plainly. This page is part of the product, not an afterthought.

Not implemented

  • Dark mode or any inverse theme.
  • Components beyond Button, Input, PasswordInput and PhoneInput.
  • A searchable country picker; PhoneInput uses a native select.
  • Figma-to-code synchronisation or a published Figma Community Library.
  • A hosted documentation service, analytics or dashboard.
  • Published npm packages. The packages are private and unpublished.
  • Phone deliverability, reachability or ownership checks.
  • A React Native, Vue, Svelte or Angular adapter.

Alpha constraints

AreaConstraint
Packages@sorleed/react 0.1.0-alpha.1 and @sorleed/cli 0.1.0-alpha.0 are private and unpublished.
ThemeLight theme only.
PhoneInputEnglish region names; native select; format validation only; international prop is accepted but unused.
PasswordInputComposes Input and Button tokens; no separate token family.
Input typesOnly text, email, tel, number and url.
CLINo --force or interactive conflict resolution; no browser verification.
FigmaPreparation and specifications, not a published library.

Certification

Sorleed has not been certified with screen readers or assistive-technology users. Automated checks and manual review are documented, but they are not certification. See Accessibility.

Support and security

  • Questions and bugs: open an issue in the repository.
  • Security: do not publish vulnerability details in an issue. Follow SECURITY.md.
  • Conduct: follow CODE_OF_CONDUCT.md. The project has a single maintainer and no independent conduct handler.
  • Contributions: read CONTRIBUTING.md.
