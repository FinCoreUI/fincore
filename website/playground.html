Interactive playground

Every example below is rendered with the shipped --fc-* tokens and the real component stylesheets linked directly from components/. No component styles are redefined on this page. Change props, states and themes and the components update immediately.

Inspect the token layer →

Source files: tokens/dist/tokens.css and components/<name>/<name>.css are linked directly from this page. Dark mode is applied with data-theme="dark" on the document element.

Three-layer tokens

Components never consume raw values. They bind to Component tokens, which alias Semantic roles, which alias Primitives. Light and Dark are owned by the Semantic layer, so one theme switch updates every component on this page.

1 · Foundation

Primitives

106 variables · Value

Raw colour scales, space, radius, type and control sizes. No theme awareness.

2 · Purpose

Semantic

63 variables · Light + Dark

Content, surface, border, action and feedback roles. The only layer with theme modes.

3 · Product

Component

599 variables · Value

Per-component geometry, typography and colour, including sm / md / lg size tokens.
