Tokens

460 --fc-* custom properties, generated from one source of truth with full dark theme support via [data-theme="dark"] and .dark.

Layers

1. Primitive

Raw palette values: neutral, blue, green, amber, red, purple, orange, white and black. Not consumed by component CSS.

2. Semantic

Roles such as color.surface.default, color.content.primary and color.border.focus.

3. Component

button.*, input.* and phone-input.*. The only layer component CSS may consume.

Aliases flow downward: component → semantic → primitive. A component token never repeats a raw value directly.

Naming

  • Groups are dot-separated: color.surface.default.
  • State suffixes are hyphenated: input.background-disabled.
  • CSS variables add the --sl- prefix and use hyphens: --sl-input-background-disabled.
--sl-color-content-primary: #18181B;
--sl-input-text: var(--sl-color-content-primary);
--sl-input-border-error: var(--sl-color-border-error);

Customise

Override semantic roles in your application theme. Do not edit generated token CSS and do not invent component names.

:root {
  --sl-color-border-focus: #0f766e;
  --sl-color-content-primary: #111827;
}

After a change, re-check text, boundary, focus and error contrast. Keep the alias chain intact.

Validation and generation

node tokens/check.mjs
node tokens/check.mjs --write

The validator checks structure, contrast pairs and generated-CSS currency. --write regenerates tokens/dist/tokens.css after an intentional source change.
